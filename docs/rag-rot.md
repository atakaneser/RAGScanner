# RAG Rot

RAG Rot is RAGScanner’s proprietary product-defined deterioration metric; it is not an established scientific standard. Marketing phrase: “Your RAG is not broken. It is rotting.”

Candidate signals include stale/versioned/contradictory/ownerless/unused content, broken URLs, missing reviews, source/index mismatch, deleted indexed sources, and retrieval deterioration. The metric requires a versioned observation window, baseline, source capability/coverage, normalization, missing-data rules, thresholds, and explanation of each contribution. It should complement—not duplicate or hide—the Health/Freshness scores. The formula remains Open Decision OD-006.
