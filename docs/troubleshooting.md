# Sorun giderme

Mevcut scaffold için `uv sync`, `uv run ragscanner --version` ve `uv run ragscanner doctor` komutlarının çıktısını kontrol edin. `doctor` credential veya ağ gerektirmez.

Scanner, parser, dashboard, worker ve connector henüz olmadığı için bunlara ait runtime troubleshooting prosedürü yoktur. Public issue’ya secret, müşteri belgesi veya özel endpoint eklemeyin.
