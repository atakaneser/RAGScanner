# RS-001: Product documents

**Objective:** Review, reconcile, and approve the Milestone 0 product documentation.  
**Rationale:** Implementation needs a truthful scope, vocabulary, audience, and edition boundary.  
**Dependencies:** None.  
**Scope:** `README`, product/features/business/community boundary, privacy/support/status docs; log contradictions, assumptions, risks, and owners.  
**Out of scope:** Application code, final legal advice, marketing launch.  
**Implementation guidance:** Hold product/security/engineering review; resolve or record every comment as an Open Decision; keep current/planned labels explicit and state that all capabilities are free.  
**Security considerations:** Do not include customer data or disclose private distribution details; review claims for false assurance.  
**Acceptance criteria:** Required documents exist, agree on terminology/status, link correctly, identify non-goals/risks, and receive named owner approval.  
**Tests:** Markdown lint/link check; manual claim and cross-document consistency review.  
**Documentation changes:** Update `docs/status/current.md`, `PLANS.md`, and changelog.  
**Completion checklist:** [ ] Reviews complete [ ] Decisions logged [ ] Links pass [ ] Status accurate [ ] No code added
